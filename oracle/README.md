# Oracle

Archivos principales:

- `sql/oracle/01_schema.sql`: crea las tablas del enunciado.
- `sql/oracle/02_carga_datos.sql`: crea el procedimiento PL/SQL para cargar datos aleatorios.
- `sql/oracle/03_consultas.sql`: contiene las cuatro consultas.
- `sql/oracle/04_explain_plan.sql`: genera Explain Plan para cada consulta.
- `sql/oracle/05_tkprof_setup.sql`: activa traza SQL para procesar con TKPROF.
- `sql/oracle/06_metricas.sql`: consulta auxiliar sobre `v$sql`.

La estructura de tablas no se modifica frente al enunciado.
